# DANTES STREET CO. Shopping Site

A modern, feature-rich clothing brand storefront built with vanilla HTML, CSS, and JavaScript.

## Features

- Branded landing hero for **DANTES STREET CO.**
- Product catalog with:
  - category filters
  - live search
  - sorting (featured, price, rating)
  - quick-view modal
- Interactive cart drawer with totals and localStorage persistence
- Dark/light mode toggle with localStorage persistence
- Drop countdown timer
- **Daily Spin Reward** for gamified discount unlocks
- **Style DNA Quiz** for personalized product recommendation
- **Recently Viewed** shelf powered by localStorage
- **Live social-proof activity banner** rotating customer activity messages
- **Street Browser Container** lookbook with tabbed style stories and quick picks
- **Wishlist favorites** with local persistence
- **Outfit Builder Lab** to mix full looks and add bundles to cart
- **Dante virtual stylist avatar** inspired by the provided brand image
- Testimonials section
- Newsletter signup interaction
- Size guide modal
- Responsive layout for mobile and desktop

## Setup

No build step required.

1. Open `index.html` directly in your browser, or
2. Run a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
